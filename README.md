# Solar System Explorer

Website interaktif untuk menjelajahi tata surya melalui visual 3D dan informasi tiap planet.

## Fitur

- Visualisasi tata surya 3D
- Halaman informasi untuk planet, Matahari, dan Bulan
- Registrasi, login, profil, serta sesi akun berbasis penyimpanan lokal browser

## Menjalankan proyek

Buka `index.html` melalui browser atau jalankan dengan local web server agar modul JavaScript dapat dimuat dengan baik.
